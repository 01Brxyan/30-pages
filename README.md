# 11 Pages 🚀

Este proyecto contiene **11 páginas** desarrolladas en **HTML**, **CSS** y **JavaScript**, ideales para practicar y aprender.

---

## 📂 Cómo abrir el proyecto

Sigue estos pasos para visualizar las páginas:

1. Clona o descarga este repositorio en tu computadora.

```bash
git clone https://github.com/01Brxyan/30-pages.git
```

2. Abre la carpeta del proyecto en tu editor de código (recomendado: **Visual Studio Code**).

3. Dentro de la carpeta encontrarás varias páginas en formato `.html`.

4. Haz doble clic en el archivo HTML que quieras abrir, o ábrelo con tu navegador preferido (Chrome, Edge, Firefox, etc.).

---

### 🌍 Si no cuentas con Visual Studio Code

Puedes abrir el proyecto directamente desde el siguiente enlace: 👉 [11 Pages](https://sweet-bavarois-cab282.netlify.app/)

---

## 📌 Requisitos

* Navegador actualizado (Chrome, Edge, Firefox, etc.)
* (Opcional) Visual Studio Code con la extensión Live Server
